## 🔍 CHECKLIST DE VALIDATION JSON

**Avant de soumettre ta correction, vérifie MANUELLEMENT** :

### 1. Structure générale
- [ ] Le JSON commence par `{` et se termine par `}`
- [ ] Toutes les accolades `{` ont leur `}` correspondante
- [ ] Tous les crochets `[` ont leur `]` correspondant
- [ ] Pas de commentaires (interdits en JSON strict)

### 2. Clés et valeurs
- [ ] Toutes les **clés** sont entre guillemets doubles : `"chapitre"`
- [ ] Toutes les **chaînes** sont entre guillemets doubles : `"valeur"`
- [ ] Pas de guillemets simples `'` (utiliser `"`)
- [ ] Guillemets échappés dans les valeurs : `\"` au lieu de `"`

### 3. Virgules
- [ ] Une virgule `,` après chaque champ (sauf le dernier)
- [ ] Pas de virgule finale avant `}` ou `]` (trailing comma)
- [ ] Une virgule entre chaque élément de tableau `[..., ...]`

### 4. Échappement des caractères
- [ ] Guillemets internes échappés : `"Il dit \"Bonjour\""`
- [ ] Antislash échappés : `\\` au lieu de `\`
- [ ] Retours à la ligne échappés : `\n` au lieu de retour réel

### 5. Structure spécifique
- [ ] `"pistes_traduction"` est un **tableau** `[...]` de chaînes
- [ ] `"glossaire"` est un **tableau** `[...]` d'objets
- [ ] Chaque objet du glossaire a tous les champs requis

## 💡 ERREURS JSON COURANTES

### ❌ **Oubli de guillemets autour des clés**
```json
{
  chapitre: "Chapter 1"  // INCORRECT
}
```
✅ **Correct** :
```json
{
  "chapitre": "Chapter 1"  // Les clés DOIVENT être entre guillemets
}
```

### ❌ **Virgule finale (trailing comma)**
```json
{
  "chapitre": "Chapter 1",
  "analyse": {...},  // Virgule en trop avant }
}
```
✅ **Correct** :
```json
{
  "chapitre": "Chapter 1",
  "analyse": {...}  // Pas de virgule après le dernier champ
}
```

### ❌ **Guillemets non échappés dans les valeurs**
```json
{
  "resume_narratif": "Il dit "Bonjour""  // Guillemets cassent le JSON
}
```
✅ **Correct** :
```json
{
  "resume_narratif": "Il dit \"Bonjour\""  // Guillemets échappés avec \"
}
```

### ❌ **Guillemets simples au lieu de doubles**
```json
{
  'chapitre': 'Chapter 1'  // JSON n'accepte que les guillemets doubles
}
```
✅ **Correct** :
```json
{
  "chapitre": "Chapter 1"  // Toujours des guillemets doubles "
}
```

### ❌ **Commentaires (interdits en JSON strict)**
```json
{
  "chapitre": "Chapter 1",  // Ceci est un commentaire INTERDIT
  "analyse": {...}
}
```
✅ **Correct** :
```json
{
  "chapitre": "Chapter 1",
  "analyse": {...}
}
```
